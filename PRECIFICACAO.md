# Precificação estimada do protótipo

Esta é uma estimativa acadêmica de custos para planejar uma eventual evolução do projeto. Os valores não são cotações comerciais.

| Item | Protótipo acadêmico | Versão de produção |
|---|---:|---:|
| HTML, CSS e JavaScript | R$ 0,00 em ferramentas gratuitas | Depende da equipe contratada |
| Hospedagem | R$ 0,00 usando execução local | Pode haver custo mensal |
| Banco de dados e backend | Não incluídos | Pode haver custo mensal |
| API de IA generativa | Não utilizada | Cobrança conforme fornecedor e volume |
| Agenda integrada | Não incluída | Desenvolvimento e manutenção |
| Domínio próprio | Não necessário | Cobrança anual conforme domínio |

## Observação
O protótipo atual não tem custo de licenciamento de software específico para executar localmente. Uma solução pública exige estimar hospedagem, domínio, segurança, manutenção, privacidade, integração com agenda e eventual consumo de API. Consulte preços atualizados dos fornecedores antes de definir um orçamento real.
